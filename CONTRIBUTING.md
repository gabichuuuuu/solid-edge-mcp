# Contributing

Thank you for your interest. The project has a single maintainer and does not accept pull requests or
other code contributions: pull requests are closed without merging. Issues are welcome.

- **Bug reports and feature requests** go to the issues, with the bug report or feature request
  template. For a bug, include the tool call, the error and the measurable result you expected
  (volume, bounding box, exported file).
- **Security problems** are not reported in public issues: see [SECURITY.md](SECURITY.md).
- **Commercial license**: open an issue with the Commercial license template, without confidential
  details, and you will get a private contact.
- **Building from source** for your own noncommercial use: see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

By taking part you agree to follow the [code of conduct](CODE_OF_CONDUCT.md).
